# PHP Raw ERP Starter Template

**এটি একটি সম্পূর্ণ PHP + MySQL ভিত্তিক ERP স্টার্টার টেমপ্লেট যা কোনো ফ্রেমওয়ার্ক ছাড়াই কাজ করে।**

## 📋 বৈশিষ্ট্য

### 1. **ব্যবহারকারী ব্যবস্থাপনা (User Management)**
- সম্পূর্ণ CRUD অপারেশন
- ব্যবহারকারী স্ট্যাটাস নিয়ন্ত্রণ

### 2. **অনুমতি ব্যবস্থা (Permission System)**
- মাস্টার অনুমতি
- ভূমিকা ভিত্তিক অনুমতি
- ব্যবহারকারী স্তরে অনুমতি ওভাররাইড

### 3. **মেনু ব্যবস্থাপনা (Menu Management)**
- বহু-স্তরের মেনু (Tree Structure)
- রুট ভিত্তিক মেনু ম্যাপিং

### 4. **অনুমতি ইঞ্জিন (Permission Engine)**
- DENY সর্বোচ্চ অগ্রাধিকার
- USER ALLOW ভূমিকা ALLOW কে ওভাররাইড করে
- ভূমিকা অনুমতি ডিফল্ট বেস

### 5. **গতিশীল সাইডবার**
- অনুমতি ভিত্তিক মেনু প্রদর্শন

### 6. **বোতাম স্তরের অনুমতি নিয়ন্ত্রণ**

### 7. **সেশন ভিত্তিক অনুমতি ক্যাশিং**
- উচ্চ কর্মক্ষমতা

### 8. **কার্যকলাপ লগ সিস্টেম**
- সমস্ত ব্যবহারকারী কার্যকলাপ ট্র্যাকিং

### 9. **Admin স্ক্রিন**
- User management screen
- Permission management screen
- Role management screen
- User permission override screen
- Menu builder screen
- Permission debug checker screen
